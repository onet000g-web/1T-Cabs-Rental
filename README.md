# 1T Cabs & Rental Android App

Android billing app based on the supplied sample bill design.

## Phone-only APK build
This project includes a GitHub Actions workflow. Upload this folder to a GitHub repository, then open **Actions → Build APK → Run workflow**. When it finishes, download the `1T-Cabs-Rental-debug-apk` artifact on your phone and install the APK.

## Main features
- Customer / vehicle / contact / trip details
- Departure and return details
- Car rent per 24 hours
- Unlimited toll entries
- Single + Single, Return Trip, and Local Pass
- Automatic toll and grand total calculation
- Sample-style bill preview
- PDF sharing / printing
- Local bill history
